## 文章背景音乐

把歌曲上传到网盘的 `music` 文件夹（后端 `UPLOAD_DIR/music`，本地为 `uploads/music`）。在新增或修改文章时，用“背景音乐”多选歌曲，可上移/下移调整循环顺序；清空选择即可关闭该文章的背景音乐。

文章右下方的音乐按钮可悬停或点击展开，支持播放、暂停、上一首、下一首及选歌。首次进入文章默认暂停；每次切换播放/暂停都会把状态保存到本地存储，打开其它带背景音乐的文章时延续该状态。离开当前文章仍会停止并释放当前音频资源。优先预加载当前和下一首，其余歌曲加载元数据；浏览器可能限制预加载，成功预加载也不能保证后续网络不中断。加载失败会跳过，可点击重新加载；全部失败时暂停并提示。

音乐使用原网盘下载接口及访问权限。要让游客听到，请确保歌曲和 `music` 文件夹可公开访问。数据库仅保存 `music/歌曲.mp3` 这样的相对路径，不保存登录令牌；旧文章不配置音乐也可正常访问。可选择 MP3、WAV、OGG、M4A、AAC、FLAC、WebM 文件，实际解码支持以浏览器为准。

自动测试（先启动本地 MongoDB、后端 `node server.js` 和前端 `npm run serve -- --host 127.0.0.1 --port 8080`）：

- `node tests/article-music.js`：后端音乐字段处理测试，使用内存替身。
- `node tests/bgm-smoke.js <playwright-core模块目录>`：使用本机 Edge 无界面测试。需要 `music` 下至少两首可公开访问的 MP3。文章与登录请求采用测试响应，音频从真实本地后端读取，不改动现有数据库。
